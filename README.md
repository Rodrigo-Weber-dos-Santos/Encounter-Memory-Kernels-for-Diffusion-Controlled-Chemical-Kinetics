Abstract: Diffusion-controlled reactions often deviate from simple exponential kinetics because reaction events depend on unresolved spatial encounter dynamics. We introduce an encounter-memory framework in which hidden spatial, or recombination dynamics are represented through temporal Volterra flux laws. The local chemical propensity is preserved within the convolution, while a memory kernel describes how unresolved pair dynamics distribute the realization of that propensity over time. The framework unifies discrete delays, ODE-chain models, gamma-distributed memory, and fractional dynamics as limiting or equivalent cases. We demonstrate its applicability to electron transfer, acid–base reactions, and proton transfer systems. First, we illustrate delayed loss fluxes associated with quenching and acid–base encounter dynamics. The third example shows that the same formalism captures positive memory feedback, where delayed geminate recombination repopulates the observed state. Compact memory laws therefore reproduce mechanistic or experimental dynamics over relevant timescales while maintaining interpretable chemical components, bridging detailed reaction–diffusion mechanisms and reduced kinetic models.
Keywords: Chemical kinetics; Nonlocal diffusion; Encounter dynamics; Memory kernels
